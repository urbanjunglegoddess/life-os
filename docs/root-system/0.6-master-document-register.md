### 1\. Purpose & How to Use

This register is the single index of record for the Life OS App's Application Root System. **Nothing is real until it has a row here.**

**All 183 pages are resolved.** Every page has been read, filled, or formally adopted with a stated verdict. There are no untouched skeletons left. What varies is ADOPTION — how a page relates to this project — and STATUS — how finished and trustworthy its content is. Those are two different axes and the register tracks both.

Because every page carries content, this register indexes at BOOK level with an explicit exception list, rather than repeating 183 rows that would say "Active" 120 times. The exceptions are where the information is.

### 2\. The Two Axes

| Axis | Values | Means |
| ---| ---| --- |
| STATUS | 🟢 Active · 🔵 In Review · 🟡 Draft · ⚪ Template · 🔴 Deprecated | How finished and trustworthy the content is |
| ADOPTION | Full · Partial · Skip · Reopened · Future-state · Paused | How the page relates to THIS project |

A page can be ⚪ Template and still be resolved — that is the correct outcome for a page whose honest verdict is SKIP, and its content says so with a trigger. A page marked SKIP is not unfinished; it is decided.

REOPENED is new as of 2026-08-26. It means a page that was correctly SKIP, whose stated trigger has now FIRED, and which therefore owes content. A reopened page is not Draft — Draft means started and deliberately unfinished. Reopened means not started and no longer excused.

### 9\. Governance

*   **Who may add rows:** Omegea Hunter. Claude Code updates rows as part of the slice it just completed — a filled page without a register row is an unfinished slice.
*   **Review cadence:** every page is walked at each phase gate. Anything 🟡 Draft or 🔵 In Review at a gate must advance or have its blocker named.
*   **Status changes:** a page's own status line and its entry here must agree. When they disagree, THE PAGE IS THE TRUTH and the register is stale — fix the register.
*   **The register indexes pages, not version numbers.** A page's version lives on that page. Duplicating it into a list here creates a second copy to maintain and a second thing to get wrong. Point at the page instead.
*   **Skip is a decision, not a gap.** A SKIP page is revisited only when its stated trigger fires. Do not re-open one because it looks empty.
*   **When a trigger fires, every page carrying it is re-examined INDIVIDUALLY.** Added 2026-08-26. A shared trigger is a bookmark, not a verdict. When UJGFREE-5913 fired it was carried by fourteen pages; eight reopened, one reopened partially, and the rest stayed Skip on their own merits with rewritten triggers. A FIRED TRIGGER MUST NEVER BE LEFT ON THE PAGE — replace it with the next real condition, or the register starts lying about what it is waiting for.
*   **A withdrawal is not a resolution.** An item withdrawn because it was recorded wrongly is labelled WITHDRAWN, never CLOSED — the difference is whether anything was fixed.
*   **A brand-level colour change re-triggers this register.** Any change to the UJG colour system means a sweep of 4.6, 4.7, 4.8, 7.9, 13.12, 6.10, 7.12, the Design & Metaphor Map, and the header accent of every page.
*   **Escalation:** there is none. Solo build. An orphaned or overdue document means the build stops until it is resolved.
